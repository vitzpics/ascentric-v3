# Organization marks

The homepage uses a broad career-experience qualifier approved by Adam, rather than labeling these organizations as Ascentric clients. The relationships and wording come from Adam’s September 30, 2026 brief and subsequent corrections; the following sources establish the artwork, not his relationship with each organization.

New assets retrieved September 30, 2026:

- Boston Public Schools: [official homepage](https://www.bostonpublicschools.org/), [compact wordmark asset](https://resources.finalsite.net/images/v1727429899/bostonpublicschoolsorg/kzknk8xck2on9pbsnrwi/BostonPublicSchoolsSticky.svg).
- City Year: [official homepage](https://www.cityyear.org/), [logo asset](https://www.cityyear.org/wp-content/themes/CityYear/dist/assets/images/logo.svg). The source SVG is intact; CSS renders it in grayscale to preserve its internal contrast in the existing monochrome proof treatment.
- Peace Corps: [official homepage](https://www.peacecorps.gov/), [white banner mark](https://www.peacecorps.gov/static/uswds/img/custom/PeaceCorps-LogoBanner-Wht.5140006fb714.svg).
- AmeriCorps: [official communication resources](https://www.americorps.gov/newsroom/communication-resources), [white-logo package](https://p1.aprimocdn.net/americorps/d18d61f1-a786-40cf-911e-aff10123d699/americorps-white-logos-original-file.zip), using `AmeriCorps_Main-logo_White/AmeriCorps_Main-logo_White.png` unchanged.

- State of Hawaiʻi: [official state public-health partner page](https://livinghealthy.hawaii.gov/visionzero/), [state seal asset](https://livinghealthy.hawaii.gov/wp-content/uploads/2025/04/Seal-of-the-State-of-Hawaii.png). Adam requested the state identity in connection with his work in Hawaiʻi’s schools; no department-specific transportation relationship is stated.
- New Orleans Health Department: [official City Council bulletin](https://content.govdelivery.com/accounts/LANOLA/bulletins/424a940), [department logo asset](https://content.govdelivery.com/attachments/fancy_images/LANOLA/2026/07/14039005/nohd-logo_original.jpg). CSS supplies grayscale/inversion and screen blending for the existing dark background; the original JPEG is intact.

Google, Microsoft, DHL, UC Berkeley, Tulane University, and InstaDeep use the existing repository assets. InstaDeep’s duplicate XML namespace attribute was removed so its SVG parses correctly; the artwork was not changed.

Nishimura & Asahi, American Humane, and Iconic Adventures remain available in the repository but are omitted from the homepage to keep the proof set to twelve. Community HealthCorps, Odanadi Seva Trust, Global Routes, Carpe Diem, and The Cookbook Project are represented in the About narrative instead of adding another logo wall.
