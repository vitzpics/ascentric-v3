# Sharing image

`ascentric-share.png` is a 1200 × 630 typographic card using the existing Cormorant Garamond typeface, Ascentric colors, wordmark text, and approved homepage headline. It is referenced by every page’s Open Graph and Twitter/X metadata.

The favicon uses the existing wordmark’s lowercase “a” with its amber dot treatment. PNG sizes are 16, 32, and 180 pixels; `favicon.ico` supplies 16, 32, and 48 pixel variants.

These are code-rendered brand assets, not generated photography. Existing website photography and the hero remain unchanged.
